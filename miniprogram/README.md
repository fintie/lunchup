# LunchUp 微信小程序

这是 LunchUp 的中文原生微信小程序客户端，与网页版共用：

```text
https://lunchup.onrender.com/api
```

目前包含：

- 邮箱注册与登录
- 职业社交匹配
- 创建和管理午餐邀约
- 工作机会
- 科技与创业新闻
- 本地活动
- LunchUp Live 和微信群亮点
- 用户确认后从剪贴板提交 AI Cafe 群聊亮点
- 个人资料

## 微信开发者工具

1. 在微信公众平台注册小程序并取得 AppID。
2. 用微信开发者工具导入仓库内的 `miniprogram` 目录。
3. 将 `project.config.json` 中的 `appid` 从 `touristappid` 改为真实 AppID。
4. 在小程序后台的“开发管理 → 开发设置 → 服务器域名”中，将以下地址加入
   `request` 合法域名：

   ```text
   https://lunchup.onrender.com
   ```

5. 开发阶段如果域名尚未配置，可以在开发者工具中临时勾选“不校验合法域名”。
   正式体验版和上线版本必须配置合法域名。

## 账号与同步

小程序使用与 LunchUp 网页相同的邮箱、密码和 JWT 登录接口。真实注册用户的资料、
匹配用户和午餐邀约存储在同一个 MongoDB 数据库中。

现有演示账号使用内存生成的 `demo_*` ID，不是 MongoDB ObjectId，因此可以浏览匹配，
但不能创建持久化午餐邀约。测试约饭同步时请注册一个真实账号。

## 外部链接

新闻、职位和活动来自多个外部站点。微信小程序的 `<web-view>` 只能打开已配置的业务
域名，因此当前版本会把外链复制到剪贴板。后续可以为通过审核的固定域名增加 WebView。
